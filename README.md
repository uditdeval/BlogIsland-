## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/uditdeval/BlogIsland-.git
```

Go to the project folder:

```bash
cd BlogIsland-
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Run Locally

```bash
npm start
```

or

```bash
npm run dev
```

---

## 🛠️ Build for Production

```bash
npm run build
```
